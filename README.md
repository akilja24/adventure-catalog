# Adventure catalogue

Story catalogue for the **Can You Survive?** (`survival/`) and **Life's Little Lessons** (`lessons/`) apps.
Served by GitHub Pages; the apps download `<variant>/index.json` on launch, so publishing here
releases a story to users **without an app update**.

```
<variant>/index.json          generated by tools/build_index.py; do not hand-edit
<variant>/achievements.json   catalogue-wide achievements
<variant>/stories/<id>.json   story definitions (schema: adventure_app/schema/story.schema.json)
<variant>/thumbs/<id>.jpg     16:9 thumbnails, referenced as "thumbs/<id>.jpg"
```

Publishing is done with the `add-story-to-app` Claude Code skill. The manual steps are:
validate, then run `python3 tools/build_index.py`, then commit and push. Pages updates within a few minutes.

Only story JSON and thumbnails live here. Videos stay on YouTube and are never copied.
`lessons/` is for the children's product, which stays disabled in public builds until compliance review.
